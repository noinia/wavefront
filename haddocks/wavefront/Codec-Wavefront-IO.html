fromFile :: MonadIO m => FilePath -> m (Either String WavefrontOBJ) Source #

Extract a WavefrontOBJ from a Wavefront OBJ formatted file. If the file specifies mtl files, these are parsed and their information is parsed as well.

rawFromFile :: MonadIO m => FilePath -> m (Either String RawWavefrontOBJ) Source #

Extract a raw WavefrontOBJ from a Wavefront OBJ formatted file. This only parses the given file, and does not dereference any materials.
